# shotsync

把截图、照片和文字暂存到自己的服务器，再从另一台设备取走。一个共享访问令牌，浏览器/PWA 界面，数据保存在服务器的本地文件夹里。

- **真跨设备**：发送和接收设备无需同时在线，也无需同一 Wi-Fi。
- **低依赖**：单个 Node.js 进程，零 npm 运行时依赖，数据就是本地文件（含元数据 sidecar），用 `rsync`/备份工具即可带走。
- **低维护**：无需数据库、CDN 或对象存储；保留 30 天由内置清扫任务自动完成。
- **自托管**：内容存放在你自己的磁盘上，用一个长随机令牌保护，无需注册或第三方账号。

| | LocalSend / PairDrop | 网盘 | **shotsync** |
|---|---|---|---|
| 互联网异步取回 | 否（大致需同时在线） | 是 | **是** |
| 需要安装的 App | 是 | 是 | **否**（PWA，可选原生客户端） |
| 服务端保存内容 | 否 | 是 | **是**（本地文件夹，保留 30 天） |
| 自托管数据可控 | — | 部分 | **完全**（自己的服务器） |
| 面向 | 文件互传 | 长期存储 | **跨设备暂存** |

> 它不是多人协作网盘，也不适合大文件归档；单项主文件上限 25 MiB，保留 30 天，用于短周期中转。

## 自己部署（约 5 分钟）

需求：Node.js 22+。数据保存在服务器本地目录（默认 `./data`，可用 `DATA_DIR` 更改），不需要数据库或对象存储。

```bash
git clone https://github.com/Defiabell/shotsync.git
cd shotsync
npm ci

# 生成一个长随机令牌并启动（可用 openssl rand -hex 32 生成）
npm run build
AUTH_TOKEN=<your-long-random-token> npm start
```

默认监听 `http://0.0.0.0:3000`。把它放到你自己的域名后面（Caddy/Nginx/任意反代终止 TLS），在每台设备打开同一地址并输入同一个令牌。

### 配置（环境变量）

| 变量 | 默认 | 说明 |
|---|---|---|
| `AUTH_TOKEN` | — | **必填。** 访问令牌，查看、上传、删除、分享签发都用它。未设置时进程拒绝启动。 |
| `PORT` | `3000` | HTTP 监听端口 |
| `DATA_DIR` | `./data` | 图片、缩略图与元数据文件存放目录 |
| `RETENTION_DAYS` | `30` | 内容保留天数，过期由内置任务自动清理；设为 `0` 禁用自动清理 |
| `DEMO_MODE` | — | 设为 `1` 进入演示模式：无需令牌可浏览示例，写入仍需令牌 |

`npm run dev` 以 tsx 直接运行 TypeScript 源码（无需构建）。

### 数据与保留

上传的图片存放在 `DATA_DIR/full/`，每个文件带一个 `<文件名>.meta.json` 元数据 sidecar（内容类型与来源）。浏览器上传会转换为 JPEG 并生成缩略图，不保留原始格式；纯文字直接存为文本项。

保留期由服务器进程内置实现：每小时（及启动时）清扫超过 `RETENTION_DAYS` 天的内容，无需配置外部生命周期规则。重要文件请另行备份。数据目录可直接用文件系统工具备份/迁移——没有隐藏状态。

## 使用

在电脑打开部署地址，输入令牌，点「+ 图片」或「✎ 文字」。在手机浏览器打开同一地址（可「添加到主屏幕」变成 PWA），列表约每 20 秒自动刷新；点开条目可保存或复制，也可生成单项临时分享链接（7 天有效，任何拿到链接的人可查看该项）。

### 客户端集成

| 集成 | 说明 |
|---|---|
| [mac/](mac/) | macOS 菜单栏客户端：自动上传新截图（`⌘⇧3/4/5`），本地生成缩略图，需 macOS 13+ |
| [shortcut/](shortcut/) | iOS 快捷指令：从任意 App 的分享表单把图片传进池子 |

手机访问无需额外配置：用浏览器打开部署地址并添加到主屏幕（Safari 分享菜单 →「添加到主屏幕」），以后点图标即可进入相册。

## 安全模型

- 持有 `AUTH_TOKEN` 即可查看、上传、删除整个池并签发分享链接；没有独立用户或分级权限。用一个足够长且随机、只在可信设备输入的令牌。
- 网页把令牌保存在浏览器 `localStorage`；用完可在公共设备上退出登录。
- 单项分享链接有效期 7 天，任何拿到链接的人可查看该项；对应内容删除后链接即失效。
- 令牌同样充当分享链接的 HMAC 密钥；更换 `AUTH_TOKEN` 会使此前签发的分享链接失效，请在各设备重新输入。
- 项目没有应用层端到端加密；它是"自己的服务器 + 共享令牌"，不是端到端加密仓库。
- 进程本身只讲 HTTP；对外服务请用反向代理终止 TLS。

## 开发

```bash
npm install        # 安装开发依赖
npm test           # vitest（node 环境，无需模拟 Workers）
npx tsc --noEmit   # 类型检查
npm run dev        # tsx 直接跑源码（.ts），改代码即重启
npm run build      # 编译到 dist/
npm start          # 运行 dist/ 产物
```

## 演示模式

设 `DEMO_MODE=1` 即得公开只读演示：无需令牌可浏览内置示例，写入仍需令牌。部署自己的演示站时，把样例图片放进 `DATA_DIR/full/` 即可（缺少 sidecar 时使用默认元数据）；让访客了解项目后，再引导他们去[自部署](#自己部署约-5-分钟)。
